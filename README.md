# Larger Project

This repository hosts application capabilities for the larger product.

## RAG Capability

The reusable RAG functionality is contained in [`rag-capability/`](rag-capability/).
It provides document ingestion, retrieval, reranking, grounded responses,
connector synchronization, and a reference client for local verification.

See [`rag-capability/README.md`](rag-capability/README.md) for setup and usage.
